# Генераторы

Скрипты в [scripts/generators](../../scripts/generators/), которые собирают файлы проекта из одного источника истины.

## Правила

- [Правила Generate](./rules/generateRule.md) — требования ко всем генераторам.

## Разделы

- [Генератор style contracts](./sections/generate-style-contracts.md) — tokens → contracts.
- [Генератор иконок](./sections/generate-icons.md) — SVG → реестр `MediaIcons`.
- [Генератор аудио](./sections/generate-audio.md) — аудиофайлы → реестр `MediaAudio`.
- [Генератор версий документации](./sections/generate-node-docs.md) — версии из `package.json` → документация.
- [Генератор WOFF2-шрифтов](./sections/generate-fonts-woff2.md) — `.ttf` → `.woff2`.
