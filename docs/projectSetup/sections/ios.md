# Запуск на iOS

Эта инструкция описывает запуск приложения на iOS через Capacitor.

## Шаг 1. Подготовьте проект

Если зависимости еще не установлены, установите их в корне `blind`:

```bash
npm install
```

## Шаг 2. Cборка web

Нужно собрать фронтенд, который потом попадет в iOS-оболочку.

```bash
npm run build
```

## Шаг 3. Синхронизация Capacitor

```bash
npx cap sync ios
```

## Шаг 4. Откройте проект в Xcode

Откройте `ios/App/App.xcworkspace` в `Xcode` и дождитесь загрузки проекта или через терминал:

```bash
npx cap open ios
```

## Шаг 5. Выберите устройство

Можно использовать:

1. iOS-симулятор;
2. подключенное физическое устройство.

## Шаг 6. Запустите приложение

Нажмите `Run` в `Xcode` и дождитесь старта приложения на выбранном устройстве.
