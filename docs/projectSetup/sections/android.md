# Запуск на Android

Эта инструкция описывает запуск приложения на Android через Capacitor.

## Шаг 1. Подготовьте проект

Если зависимости еще не установлены, установите их в корне `blind`:

```bash
npm install
```

## Шаг 2. Cборка web

Нужно собрать фронтенд, который потом попадет в Android-оболочку.

```bash
npm run build
```

## Шаг 3. Синхронизация Capacitor

```bash
npx cap sync android
```

## Шаг 4. Откройте Android-проект

Откройте проект в `Android Studio` или через теминал:

```bash
npx cap open android
```

## Шаг 5. Выберите устройство

Можно использовать:

1. Android-эмулятор;
2. подключенное физическое устройство.

## Шаг 6. Запустите приложение

Нажмите `Run` в `Android Studio` и дождитесь старта приложения на выбранном устройстве.
