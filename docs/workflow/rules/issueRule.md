# Правила создания Issue

Как оформлять задачу или баг.

## Правила

1. Issue заполняется по шаблону [issue.md](../../../.github/ISSUE_TEMPLATE/issue.md).
2. Заголовок коротко описывает проблему или задачу.
3. Для бага шаги воспроизведения пишутся так, чтобы другой человек повторил проблему без уточнений.
4. Для задачи описывается результат, понятный не только разработчику.

## Разделы шаблона

| Раздел | Что писать |
|---|---|
| Описание | суть проблемы или задачи |
| Способ воспроизведения | точные шаги |
| Ожидаемый результат | как должно работать после решения |
| Список ссылок | макеты, спецификации, обсуждения |
| Скриншоты / логи | всё, что помогает быстрее понять проблему |
| Связанные задачи | связанные issue и зависимости |
