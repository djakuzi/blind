# Правила создания Request

Как оформлять реквест на слияние.

## Правила

1. Описание заполняется по шаблону [pull_request_template.md](../../../.github/pull_request_template.md) — шаблон и есть источник структуры.
2. Заголовок может начинаться с номера issue: `Issue 123. Краткое описание`.
3. Связь с issue — через `Closes #123`, тогда issue закроется после слияния.
4. Изменения описываются понятным языком, без лишней технической детализации, чтобы их понимали все участники.
5. Если работа не закончена, заголовок начинается с `Draft: `.
