# Правила Generate

Общие правила для генераторов в `scripts/generators`.

## Команда и файл

1. Скрипт лежит в `scripts/generators/`.
2. Команда в `package.json` — `app:generate:<что генерирует>`, например `app:generate:example-assets`.
3. Один генератор — одна задача.

## Источник данных

1. У генератора один явный источник истины (`package.json`, tokens, папка ассетов).
2. Данные не дублируются вручную в нескольких местах.
3. Нет обязательного источника — генератор завершается понятной ошибкой.

## Изменение файлов

1. Генератор меняет только свои файлы.
2. В текстовых файлах область изменения ограничена маркерами, шаблоном или предсказуемым участком.
3. Ручной текст вокруг сгенерированного участка не ломается.
4. Generated-файлы не правятся руками — меняется источник и генератор запускается снова.

## Предсказуемость

1. Одинаковый вход — одинаковый результат.
2. Нет зависимости от порядка файлов, окружения терминала, ручных действий.

## Вывод

1. Генератор сообщает, что обновил, или явно — что обновлять нечего.
2. Ошибка указывает, что именно не найдено или настроено неверно.

## Документация генератора

Каждый генератор описан отдельным файлом в `docs/client/generators/sections/`:

1. что генерирует;
2. источник данных;
3. команда запуска;
4. какие файлы обновляет;
5. когда запускать;
6. маркеры, флаги, режимы — если есть.

## Когда нужен генератор

| Нужен | Не нужен |
|---|---|
| повторяемое изменение, важен единый результат | разовое изменение без устойчивого паттерна |
| структура вычисляется автоматически | |
