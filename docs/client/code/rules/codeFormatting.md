# Форматирование кода

Форматирование делает Prettier, ошибки и правила проекта проверяет ESLint ([eslint.config.js](../../../../apps/client/eslint.config.js)). Руками форматирование не подбирается.

## Команды

| Команда | Что делает |
|---|---|
| `npm run format:check` | проверка форматирования |
| `npm run format` | автоформатирование |
| `npm run lint` | проверка ESLint |
| `npm run lint:fix` | автоисправление ESLint |

## Что задаёт Prettier

Источник истины — [prettier.config.js](../../../../apps/client/prettier.config.js). Основное:

1. Отступ — 2 пробела, без табов.
2. Точка с запятой и одинарные кавычки.
3. Trailing comma в многострочных объектах и массивах.
4. Ширина строки — 140.
5. Переводы строк — `lf`, перевод строки в конце файла.

Vue-файлы форматируются целиком: `script`, `template`, `style`. Markdown в Prettier не входит (`.prettierignore`).

## Чего не делать

1. Не переносить короткие выражения вручную — Prettier сам решает, когда переносить.
2. Не разделять пустыми строками каждое CSS-свойство — пустая строка только между смысловыми блоками.
