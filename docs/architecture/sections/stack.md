# Стек приложения

В проекте используется такой набор технологий:

1. `Vue 3.5.x` - UI-слой приложения.
2. `TypeScript 5.9.x` - основной язык кода.
3. `Vite 7.x` - сборка и локальный dev-сервер.
4. `Pinia 3.x` - управление состоянием.
5. `Vue Router 5.x` - маршрутизация.
6. `Capacitor 8.x` - мобильная обвязка для Android и iOS.

### Поддержка окружения

1. `Node.js` версии `>=v26.0.0`.
2. `npm` из поддерживаемой версии `Node.js`.
3. `Android` и `iOS` подключаются через `Capacitor`.

### Стили и ресурсы

1. Для стилей используются `css`.
2. Токены и контрактные стили лежат в `src/styles`.
3. Статические ассеты лежат в `src/assets`.
