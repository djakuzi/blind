# Стек приложения

В проекте используется такой набор технологий:

1. `Vue 3.5.x` - UI-слой приложения.
2. `TypeScript 6.0.x` - основной язык кода.
3. `Vite 8.1.x` - сборка и локальный dev-сервер.
4. `Pinia 4.0.x` - управление состоянием.
5. `Vue Router 5.x` - маршрутизация.
6. `@vitejs/plugin-vue 6.x` - интеграция Vue с Vite.

### Поддержка окружения

1. `Node.js` версии <span hidden data-doc-marker="node-version:start"></span>`>=22.12.0`<span hidden data-doc-marker="node-version:end"></span>.
2. `npm` из поддерживаемой версии `Node.js`.
3. `Git` любой актуальной стабильной версии.
4. Для web-режима используется локальный dev-сервер `Vite`.
5. Для Android и iOS проектная документация предусматривает использование `Capacitor`.
