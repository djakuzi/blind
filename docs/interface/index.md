## Аудио интерфейса

UI использует общий platform audio API и типизированные идентификаторы аудиоресурсов, не обращаясь напрямую к native SDK. Конкретный способ воспроизведения определяется платформенным слоем.

Звуки назначаются по смыслу взаимодействия, а не автоматически всем интерактивным компонентам. Пользовательская настройка звука должна применяться согласованно ко всему интерфейсу.

Принципы звукового дизайна описаны в [Аудио](../audio/index.md).
