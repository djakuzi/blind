## Звук в интерфейсе

1. UI воспроизводит звук через `useAudio` и общий platform audio API, с типизированными id ресурсов — без обращения к SDK.
2. Компонент получает звук через prop `sound` (вместе с вибрацией — через общий фрагмент props обратной связи).
3. Звук назначается по смыслу взаимодействия, а не каждому интерактивному компоненту.
4. Пользовательская настройка звука применяется ко всему интерфейсу одинаково.
