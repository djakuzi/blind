# Localization

| Команда | Назначение |
| --- | --- |
| `locale check` | Проверка JSON, ключей, плейсхолдеров, метаданных и SVG |
| `locale languages` | Список языков и проверка ресурсов |

```bash
npm run cli -- locale check
```

Сверяются переводы из `public/lang`. Проверка ничего не перезаписывает; дополнительные формы множественного числа могут различаться между языками.
