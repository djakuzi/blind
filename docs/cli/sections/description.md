# Описание Blind CLI

Blind CLI — терминальная утилита для запуска, сборки, проверки и обслуживания проекта.

- **Project** — информация о проекте и проверка окружения.
- **Development** — запуск Web и Desktop для разработки.
- **Platforms** — работа с Android и iOS.
- **Build / Package** — сборка приложения и создание дистрибутивов.
- **Generate** — обновление генерируемых ресурсов.
- **Verify / Fix** — проверки проекта и исправление форматирования.
- **Localization** — проверка переводов и языков.
- **Git** — работа с ветками и состоянием репозитория.
- **Clean** — очистка сборок и переустановка зависимостей.
