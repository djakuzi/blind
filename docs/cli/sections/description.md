# Описание Blind CLI

Терминальная утилита для запуска, сборки, проверки и обслуживания проекта. Запуск — `npm run cli`.

| Раздел | Что делает |
|---|---|
| Project | информация о проекте, проверка окружения |
| Development | запуск Web и Desktop |
| Platforms | Android и iOS |
| Build / Package | сборка и дистрибутивы |
| Generate | обновление генерируемых файлов |
| Verify / Fix | проверки и исправление форматирования |
| Localization | проверка переводов и языков |
| Git | ветки и состояние репозитория |
| Clean | очистка сборок и переустановка зависимостей |
