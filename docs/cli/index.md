# Blind CLI

Терминальная утилита для повседневной работы с проектом: запуска, сборки, проверки и обслуживания.

Запуск: `npm run cli`.

## Разделы

- **Project** — информация о проекте и проверка готовности окружения.
- **Development** — запуск Web- и Desktop-версий для разработки.
- **Platforms** — работа с Android и iOS.
- **Build / Package** — сборка приложения и подготовка дистрибутивов.
- **Generate** — обновление генерируемых ресурсов проекта.
- **Verify / Fix** — проверка проекта и исправление ошибок форматирования.
- **Localization** — проверка переводов и списка языков.
- **Git** — работа с ветками и состоянием репозитория.
- **Clean** — очистка результатов сборки и переустановка зависимостей.
