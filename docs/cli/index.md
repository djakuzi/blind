# Blind CLI

Терминальная утилита проекта. Позволяет запускать разработку, сборки, диагностику и обслуживание из одного меню.

```bash
npm run cli
npm run cli -- help
npm run cli -- <раздел> <команда> [аргументы]
```

Меню работает в отдельном экранном буфере терминала: переходы между разделами не добавляют новые меню в историю вывода. При запуске команды тот же экран очищается и показывает вывод операции. Повторный запуск заменяет прошлый вывод, а не дописывает его в основной терминал. По Enter возвращаемся к меню.\n\nИнтерактивное меню использует цветовые акценты в совместимых терминалах и поддерживает `NO_COLOR`.\n\nИнтерактивное меню: **↑/↓** — перемещение, **Enter** — выбор, **Esc/←** — назад. Сначала выберите раздел, затем команду. После выполнения команды вернитесь в меню нажатием Enter.\n\nДля первоначального развёртывания проекта используйте [инструкцию по запуску](../projectSetup/sections/cli.md).
