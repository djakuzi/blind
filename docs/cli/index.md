# Blind CLI

Терминальная утилита проекта. Позволяет запускать разработку, сборки, диагностику и обслуживание из одного меню.

```bash
npm run cli
npm run cli -- help
npm run cli -- <раздел> <команда> [аргументы]
```

Для первоначального развёртывания проекта используйте [инструкцию по запуску](../projectSetup/sections/cli.md).
