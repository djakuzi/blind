# Нативные настройки

Локальные файлы с нативными секретами. Они не коммитятся.

| Платформа | Файл | Исключён из git |
|---|---|---|
| Android | `android/local.properties` | да, `android/.gitignore` |
| iOS | `ios/local.xcconfig` | правила нет — не коммитить вручную |

Недостающие значения или готовый файл — запросить у команды.
