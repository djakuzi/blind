# Настройка окружения

В проекте используются mode-файлы окружения Vite:

- `.env.debug` - окружение для debug-запуска и debug-сборки;
- `.env.prod` - окружение для production-сборки и проверки production-конфига.

Переменные из этих файлов читает `src/config`, он собирает из них конфиг приложения.

Если каких-то значений не хватает, можно запросить готовые значения у команды или отдельно уточнить нужные данные.

# Переменные окружения

## App

- `APP_MODE` - Режим приложения. `debug` для debug-окружения, `prod` для production.

- `APP_VERSION` - Версия приложения.

- `APP_DEEPLINK_SCHEME` - Схема deeplink приложения без `://` и без двоеточия. Например: `blind`.

- `APP_STATE_CHECK_VERSION` - Включает стартовую проверку версии приложения.

- `APP_STATE_CHECK_VERSION_PROMPT` - Включает показ нижнего листа с предложением обновить приложение через, если версия с сервером отличается от текущей и обновление не заблокировано отложенным отказом.

## Api

- `API_TARGET` - Адрес API для текущего mode-файла.
