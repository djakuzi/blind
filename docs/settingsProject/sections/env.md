# Настройка окружения

В проекте используется локальный файл `.env`, который обычно создается на основе шаблона:

```bash
cp .env.template .env
```

Переменные из этого файла читает `src/shared/config`, он собирает из них конфиг приложения.

Если каких-то значений не хватает, можно запросить готовый `.env` у команды или отдельно уточнить нужные данные.

# Переменные окружения

## App

- `APP_MODE` - Режим приложения. Обычно `dev` для локальной разработки.

- `APP_VERSION` - Версия приложения.

- `APP_DEEP_LINK_SCHEME` - Схема deeplink приложения без `://` и без двоеточия. Например: `blind`.

- `APP_STATE_CHECK_VERSION` - Включает стартовую проверку версии приложения.

- `APP_STATE_CHECK_VERSION_PROMPT` - Включает показ нижнего листа с предложением обновить приложение через, если версия с сервером отличается от текущей и обновление не заблокировано отложенным отказом.

## Api

- `API_TARGET_PROD` - Адрес production API.

- `API_TARGET_DEV` - Адрес development API.
