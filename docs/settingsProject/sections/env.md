# Переменные окружения

Mode-файлы Vite и переменные, из которых `src/config` собирает конфиг приложения.

## Файлы

| Файл | Для чего |
|---|---|
| `.env.debug` | debug-запуск и debug-сборка |
| `.env.prod` | production-сборка и проверка production-конфига |
| `.env.template` | образец со всеми переменными |

Недостающие значения — запросить у команды.

## Переменные

| Переменная | Значение |
|---|---|
| `APP_MODE` | `debug` или `prod` |
| `APP_VERSION` | версия приложения |
| `APP_DEEPLINK_SCHEME` | схема deeplink без `://`, например `example` |
| `APP_STATE_CHECK_VERSION` | включает проверку версии при запуске |
| `APP_STATE_CHECK_VERSION_PROMPT` | предлагать обновиться, если версия на сервере другая и пользователь не отложил обновление |
| `API_TARGET` | адрес API для этого режима |
