# Форматирование кода

Стиль форматирования кода в проекте контролируется через `ESLint`.
Актуальная конфигурация находится в [eslint.config.js](/Users/djakuzi/project/blind/eslint.config.js).

## Команды

1. Проверка форматирования и style-правил запускается через `npm run lint`.
2. Автоматическое исправление форматирования запускается через `npm run lint:fix`.
3. Команда `eslint .` означает проверку всего проекта от текущей директории.
4. Команда `eslint . --fix` означает проверку всего проекта с автоматическим исправлением поддерживаемых правил.

## 1. Отступы

1. Для `js`, `ts` и Vue template используется отступ в `2` пробела.
2. Не используются табы для выравнивания кода.

Пример:

```ts
const config = {
  title: 'blind',
  enabled: true,
}
```

## 2. Точки с запятой

1. В `js`, `ts` и Vue script-блоках используются `;`.

Пример:

```ts
const title = 'blind';
```

## 3. Кавычки

1. Для строк в `js`, `ts` и Vue script-блоках используются одинарные кавычки.

Пример:

```ts
const title = 'blind';
```

## 4. Объекты

1. В объектах используются пробелы внутри фигурных скобок.
2. После двоеточия ставится пробел.
3. В многострочных объектах используется trailing comma.

Пример:

```ts
const user = {
  name: 'Alex',
  active: true,
};
```

## 5. Массивы

1. В массивах не используются пробелы внутри квадратных скобок.
2. В многострочных массивах используется trailing comma.

Пример:

```ts
const ids = [1, 2, 3];
```

## 6. Пустые строки и пробелы

1. Не допускаются хвостовые пробелы в конце строки.
2. Не допускается больше одной пустой строки подряд.
3. В конце файла должен быть перевод строки.

## 7. Блоки и операторы

1. Перед `{` ставится пробел.
2. В бинарных операциях используются пробелы вокруг операторов.
3. В шаблонных строках внутри `${}` лишние пробелы не ставятся.

Пример:

```ts
if (isReady) {
  const text = `Hello ${name}`;
}
```

## 8. Vue template

1. Для Vue template используется отступ в `2` пробела.

Пример:

```vue
<template>
  <ViewLayout>
    <AppTitle />
  </ViewLayout>
</template>
```

## 9. CSS

1. Для CSS сохраняется обычный CSS-синтаксис с `;`.

Пример:

```css
.app-card {
  display: flex;
  gap: 8px;
}
```
