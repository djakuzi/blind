# Props компонентов

Как устроить публичный API Vue-компонента: что лежит на верхнем уровне, как переиспользовать общие props и как давать настраивать вложенные компоненты.

## Именование и экспорт

1. Интерфейс называется `Props<ИмяКомпонента>`.
2. Props переиспользуемого компонента экспортируются, чтобы родители собирали из них свои типы.
3. Короткое `interface Props` — только для локального компонента, чьи props никто не импортирует.
4. Вынесенный тип группы называется от компонента: `tAppExampleTextOptions`.

## Общие фрагменты props

Повторяющиеся группы props (размеры, отступы, поверхность, `disabled`, доступность и т.д.) лежат в `src/app/shared/types/props/`.

1. Компонент подключает их через `extends`, а не описывает те же поля заново.
2. Новый фрагмент добавляется, только если он нужен нескольким компонентам.

## Верхний уровень

На верхнем уровне — всё, что относится к самому компоненту: значение, состояние, вариант, размер, ширина, отступы, поверхность, `disabled`, поведение, доступность.

Свои характеристики не прячутся в группы вроде `optionsLayout` или `optionsSurface`.

## Группы `options*`

Группа `options<Имя>` показывает, **какой вложенный компонент** можно настроить снаружи и **какие его поля**.

1. Имя группы указывает на вложенный компонент: `optionsChild` → `AppChild`.
2. Тип строится от props вложенного компонента через `Omit` или `Pick`.
3. Из группы исключается то, чем управляет родитель: общее состояние, размеры, которые родитель задаёт сам, значения, вычисляемые внутри.
4. Общее состояние (`disabled`, `size`) задаётся один раз на родителе и передаётся вниз явно.
5. Полный интерфейс props вложенного компонента не наследуется.
6. Самостоятельная часть компонента без своего компонента (заголовок модалки, разделитель списка) может иметь группу `options<Часть>` из общих фрагментов. Корень самого компонента так не описывается.
7. Вложенность не создаётся ради единообразия.

```ts
export interface PropsAppParent extends PropsWidth, PropsSizeVariant, PropsDisabled {
  // width и size задаёт AppParent — их нет в группе
  optionsChild?: Omit<PropsAppChild, 'width' | 'size'>;
}
```

Неправильно — свои характеристики спрятаны в группу:

```ts
export interface PropsAppParent {
  optionsLayout?: PropsWidth & PropsPadding;
}
```

## Умолчания внутри группы

1. В `withDefaults` группа по умолчанию `undefined`.
2. Умолчания полей группы задаются в `computed`. Значение, переданное снаружи, важнее.

```ts
const childProps = computed<NonNullable<PropsAppParent['optionsChild']>>(() => ({
  ...props.optionsChild,
  exampleField: props.optionsChild?.exampleField ?? 'default',
}));
```

## Передача во вложенный компонент

Группа передаётся через `v-bind`, свойства родителя — явно и перекрывают группу. События и слоты пробрасываются явно.

```vue
<AppChild v-bind="childProps" :size="size" :disabled="disabled" />
```
