# Звуковой дизайн интерфейса

Единый звуковой язык UI: по нему создаются, подбираются и оцениваются новые интерфейсные звуки. Конкретные файлы и игровые звуки (выстрелы, попадания) сюда не входят.

## Суть

Интерфейс — цифровой объект, который физически реагирует на действия.

| Платформа | Принцип |
|---|---|
| Mobile | **Haptic-First**: звук + вибрация = одно тактильное событие |
| Desktop, Web без вибрации | **Invisible Haptics**: звук сам передаёт ощущение физического отклика |

Звук — часть обратной связи вместе с визуалом и вибрацией, а не декорация. Он передаёт контакт, давление, сопротивление, фиксацию, натяжение, освобождение.

## Звук и вибрация

1. Проектируются вместе, а не «сначала звук, потом вибрация».
2. Совпадают по началу, длительности, интенсивности, атаке, динамике и завершению.
3. Короткий импульс — короткий отклик; мягкое освобождение — мягкий отклик; важное подтверждение — плотнее и сильнее.
4. Без вибрации звук должен оставаться убедительным: чёткая атака, короткие transients, ощущение массы, контролируемый low-mid, контраст напряжения и освобождения.

## Характер

| Качество | Значит |
|---|---|
| minimal | без лишних слоёв |
| tactile | ощущение физического контакта |
| precise | ясное начало и конец |
| dense | короткий, но не пустой |
| controlled | без хаотичной динамики и агрессии |
| modern | технологичный, но не модный на сезон |
| slightly dark | глубина и лёгкая неизвестность |
| restrained | не требует внимания без причины |

Технологичность передаётся точностью и материалом, а не sci-fi сигналами.

### Материал

Синтетическому звуку придаётся масса через ассоциации: мягкое стекло, плотный пластик, микромеханика, мембрана, пружина, электромагнитный импульс, давление, вакуум, короткий резонанс. Звучать буквально как эти материалы не нужно — характер между цифровой системой и физическим объектом.

## Форма звука

Основа: `attack → body → release`.

Звук передаёт направление события, чтобы различались: действие принято, состояние изменилось, ожидается продолжение, действие завершено, отменено, запрещено.

### Составляющие

Не каждый звук содержит все.

| Часть | Роль | Ограничение |
|---|---|---|
| transient | ощущение контакта | читаемый, но не резкий |
| body | масса и давление | не обязательно громкий |
| тон | направление или состояние | вторичен, не превращать UI в ноты |
| текстура | идентичность системы | очень тонкая, не самостоятельный эффект |
| низ | масса, усиление Invisible Haptics | часть импульса, не bass hit; смысл не только в низах |
| хвост | естественное завершение | короткий, без длинного reverb |

## Пространство и частоты

1. Близко и сухо: dry, close, focused, compact. Стерео — только для крупных переходов. Смысл сохраняется в mono.
2. Основа — mid и low-mid. Высокие — для ясности атаки, не доминируют. Низ — дополнительная масса.
3. Звук работает на динамике телефона, ноутбука, в наушниках и колонках.
4. Приоритет: `тактильный отклик → информация → текстура → тональность`.

## Сила и повторение

1. Важность передаётся плотностью, глубиной, атакой, длительностью, слоем, low-mid и вибрацией, а не громкостью.
2. Чем чаще звучит эффект, тем он короче, проще, тише по яркости и менее мелодичный. Редкие события могут быть богаче.
3. Одно действие звучит узнаваемо: случайная вариативность не ломает язык.
4. Иерархия: маленькое действие не звучит как важное подтверждение, звуки не соревнуются за внимание.

## Когда нужен звук

Звук оправдан, когда помогает почувствовать изменение состояния или результат: значимый выбор, подтверждение, смена состояния control, завершение долгого действия, отмена, ошибка или запрет, важное новое состояние, результат процесса, важный переход.

Интерактивность компонента — не причина для звука.

## Чего избегать

1. Generic clicks и стандартные уведомления.
2. Arcade, 8-bit, chiptune, casino-эстетика.
3. Чрезмерный cyberpunk, навязчивый glitch, sci-fi лазеры.
4. Длинные мелодичные подтверждения, агрессивные whoosh, длинный reverb.
5. Cinematic impacts и bass drops для обычных действий.
6. Резкие высокие частоты.
7. Звук на каждый hover, tap или focus.
8. Эффекты, раздражающие после нескольких повторений.

Хороший отдельный звук не подходит, если выбивается из системы.

## Проверка нового звука

1. Передаёт физический характер взаимодействия?
2. Работает как одно событие с вибрацией?
3. Убедителен без вибрации на desktop?
4. Соответствует материалу и характеру проекта?
5. Не слишком заметен для своей частоты?
6. Читается на мобильном и desktop-аудио?
7. Смысл не только в стерео или низах?
8. Не звучит как generic mobile UI?
9. Не слишком музыкальный или декоративный?
10. Звук здесь вообще нужен?
