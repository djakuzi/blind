# Аудио-ассеты и громкость

Аудио-реестр проекта генерируется из файлов в `src/assets/audio`.

Для каждого asset generator формирует id, путь, тип, количество каналов и базовый `volume`.

## Volume

При первой генерации нового audio id получает `volume: 1`.

После этого `volume` можно настроить вручную в сгенерированном `src/core/media/audio/const.ts`. При следующем запуске generator читает предыдущий registry и сохраняет существующее значение по тому же audio id.

Остальные generated-поля пересобираются из структуры файлов и не наследуются из предыдущего registry.

Если audio id изменился из-за переименования или переноса файла, generator считает его новым asset и снова ставит `volume: 1`.

`volume` используется для выравнивания воспринимаемой громкости между SFX. Он не должен заменять sound design самого файла: характер, динамика, атака и спектр остаются частью WAV/MP3.

Обычные UI SFX следует сводить к согласованной воспринимаемой громкости, а более значимые события могут быть немного сильнее только когда это оправдано их ролью.


## Применение volume

Базовый `volume` asset является частью его сведения и применяется в момент воспроизведения, а не фиксируется в preload.

Runtime `volume`, переданный в `play`, `loop` или `setLoopVolume`, является множителем базового уровня:

`final volume = asset volume × runtime volume`.

Если runtime `volume` не передан, его множитель равен `1`.

Это позволяет отдельно хранить выравнивание громкости между assets и динамически менять интенсивность конкретного взаимодействия. Например, `hold-progress` сохраняет свой ramp `0.1 → 0.48`, а базовый `volume` самого asset масштабирует весь ramp целиком.

Preload отвечает только за подготовку аудиоданных и не должен замораживать базовую громкость на время сессии.
