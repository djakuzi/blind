# Аудио-ассеты и громкость

Как звуковые файлы попадают в реестр и как работает их громкость.

## Реестр

Реестр генерируется из файлов в `src/assets/audio` в `src/core/media/audio/const.ts`. Для каждого файла: id, путь, тип, количество каналов, базовый `volume`.

## Базовый volume

1. Новый id получает `volume: 1`.
2. `volume` можно настроить вручную в `const.ts` — генератор сохранит его для того же id. Остальные поля пересобираются.
3. Переименовали или перенесли файл — id новый, `volume` снова `1`.
4. `volume` выравнивает воспринимаемую громкость между звуками и не заменяет сведение самого файла.
5. Обычные UI-звуки сводятся к одной воспринимаемой громкости; важные события могут быть чуть громче, если это оправдано.

## Применение

```text
итоговая громкость = volume ассета × runtime volume
```

1. Runtime volume передаётся в воспроизведение (`play`, `loop`, `setLoopVolume`); не передан — равен `1`.
2. Так можно менять интенсивность взаимодействия (например, нарастание громкости), а базовый volume масштабирует всё нарастание целиком.
3. Базовый volume применяется в момент воспроизведения. Preload только готовит данные и громкость не фиксирует.
