# Художественное направление и анти-шаблоны

## Откуда берётся характер

- Выразительные решения берутся из сути игры: характер PvP, динамика, атмосфера, утверждённая палитра, назначение экрана. Не из модных шаблонов.
- Не превращай Blind автоматически в военный шутер, киберпанк или другой готовый жанровый стиль.
- Перед дизайном экрана сформулируй: для кого экран, какая у него главная задача, какое действие игрок должен сделать.

## Два прохода

1. **План.** Коротко опиши: палитра (только из tokens), роль типографики, концепция раскладки (можно ASCII-схемой), 2–3 принципа, которые делают этот экран особенным.
2. **Сверка с задачей.** Спроси себя: не получился бы такой же план для любого похожего экрана любой игры? Если да — переделай эту часть и скажи, что изменил и почему. Только потом реализация.

## Признаки шаблонного «AI-дизайна» (избегать, если пользователь явно не просит)

- Контент нарезан на одинаковые скруглённые карточки с одинаковой серой тенью.
- Один и тот же border-radius на всём, независимо от иерархии.
- Градиентные пятна как декорация.
- ALL-CAPS подпись с разрядкой над каждым заголовком.
- Одно слово в заголовке выделено цветом или курсивом.
- Нумерация 01 / 02 / 03 там, где нет реальной последовательности.
- Строки вида «A · B · C» и «СЛОВО — фрагмент».
- Стрелка «→» в каждой кнопке.
- Fade-and-slide-up на каждом блоке и hover-анимация на каждой карточке.

## Сдержанность

- Смелость тратится в одном месте: один запоминающийся элемент, всё вокруг спокойное.
- Перед завершением убери один лишний декоративный элемент.
- Структурные элементы (рамки, разделители, номера, подписи) должны нести смысл, а не украшать.
- Типографика несёт характер: одна-две гарнитуры из проекта (`src/assets/fonts`), чёткая шкала размеров из tokens.

## Тексты в интерфейсе

- Слова — часть дизайна. Сначала реши, что экран должен сказать, потом — как.
- Называй вещи так, как понимает игрок, а не как устроена система.
- Кнопка говорит, что произойдёт: «Начать матч», а не «Отправить». Одно действие — одно название на всём пути.
- Ошибка объясняет, что случилось и что делать. Пустой экран предлагает действие.
- Весь текст — через Locale (`docs/interface/sections/localization.md`).

## Разнообразие вариантов

- Для открытого исследования — 2–3 существенно разных направления.
- Варианты различаются композицией, силуэтом, ритмом, иерархией, метафорой — не только цветом.
- Не выдавай количество вариантов за качество. Для правки уже выбранного варианта продолжай его, не начинай заново.
