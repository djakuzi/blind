# Проверка анимаций

Запуск — по правилу «Визуальная проверка» из `AGENTS.md`: сначала спроси пользователя. Не называй анимацию плавной по одному скриншоту или по коду.

## Инструмент motion-probe

Файл: `.ai-core/skills/ui-animation/tools/motion-probe.js`. Подключение на открытой странице dev-сервера (через инструмент выполнения JS в браузере или консоль):

```js
(0, eval)(await (await fetch('/.ai-core/skills/ui-animation/tools/motion-probe.js')).text());
```

### Что запустилось и как — `record`

```js
const btn = [...document.querySelectorAll('button')].find((b) => b.textContent.includes('…'));
await __motion.record(() => btn.click(), 1500);
```

Возвращает список: тип (`CSSTransition` / `CSSAnimation`), что анимируется (свойство или keyframes), элемент, длительность, задержку, повторы, easing.

Проверяй:

- анимируются только `transform`/`opacity` (или осознанно другое);
- длительности и easing совпадают с tokens и ожиданием (уход быстрее входа);
- нет неожиданных анимаций (лишние свойства, `all`, бесконечные циклы там, где их быть не должно).

### Кадры середины перехода — `slowmo`

```js
__motion.slowmo(4000);   // все transition = 4000 мс
// выполнить действие, сделать скриншоты через ~25%, 50%, 75%
__motion.slowmo(false);  // выключить
```

Работает и для Vue `<Transition>`. Все длительности становятся одинаковыми — смотри форму и путь движения, а не тайминг (тайминг — из `record`).

### Точная заморозка — `freeze` / `seek`

```js
await __motion.freeze(() => el.classList.add('is-open'));
__motion.seek(0.5);      // кадр на 50%
// скриншот
__motion.release();
```

Только для анимаций, которыми не управляет Vue `<Transition>` (hover, `:active`, циклы, переключение классов). Vue `<Transition>` удаляет элемент по своему таймеру — для него используй `slowmo`.

После проверки перезагрузи страницу, чтобы снять все вмешательства.

## Что проверить

1. **Вход и выход** — отдельно; уход быстрее входа.
2. **Повтор** — действие два раза подряд быстро: нет «борьбы» эффектов, элемент приходит в покой.
3. **Прерывание** — отмена посреди анимации: элемент корректно возвращается, ввод не заблокирован.
4. **Reduced motion** — повтори с эмуляцией `prefers-reduced-motion: reduce` (`__motion.reduced()` показывает текущее значение): движение сокращено, обратная связь осталась.
5. **Размеры** — телефон landscape и desktop: смещения в `rem` выглядят соразмерно.
6. **Темы** — светлая и тёмная, если анимация меняет цвет.
7. **Консоль** — без ошибок.
8. **Производительность** — тяжёлые эффекты (blur, backdrop-filter) на мобильном размере: нет заметных подтормаживаний. Реальное устройство обычно недоступно — так и напиши.

## Отчёт

- Что анимируется и с какими параметрами (из `record`).
- Кадры середины для ключевых переходов.
- Результаты повтора, прерывания, reduced motion.
- Что не проверено (реальное устройство, Electron, низкопроизводительные телефоны).
