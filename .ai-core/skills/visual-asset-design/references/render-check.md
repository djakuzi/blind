# Визуальная проверка SVG

Цикл для нового или изменённого SVG. Запуск — по правилу «Визуальная проверка» из `AGENTS.md`, после согласия пользователя:

```
нарисовал → отрендерил → посмотрел → оценил → исправил → отрендерил снова → … → сдал
```

Ориентир по числу итераций: простая иконка — 1–2, сложная иконка или логотип — 2–4, иллюстрация — 3–6.

## Стенд svg-preview

Файл: `.ai-core/skills/visual-asset-design/tools/svg-preview.html`. Открывается через dev-сервер проекта.

1. Запусти сервер: конфигурация `web-dev` в `.claude/launch.json` или `npm run dev`. Порт может отличаться от 5173 — смотри вывод.
2. Открой:

```
http://localhost:<port>/.ai-core/skills/visual-asset-design/tools/svg-preview.html?src=/src/assets/icons/<group>/<name>-dark.svg,/src/assets/icons/<group>/<name>-light.svg
```

Параметры:

| Параметр | Значение |
|---|---|
| `src` | один или несколько путей через запятую |
| `ref` | эталон (макет, PNG/SVG) — накладывается полупрозрачно на крупные превью, прозрачность регулируется ползунком |
| `bg` | `auto` (по суффиксу файла), `dark`, `light`, `both` |

Черновики можно держать во временной папке внутри проекта и открывать оттуда же; после проверки — перенести в `src/assets/` и удалить черновик.

## Что показывает стенд

- **Цифры**: viewBox, bbox геометрии, смещение центра bbox от центра viewBox (`dx`, `dy`), поля с каждой стороны, процент заполнения.
- **Предупреждения**: нет viewBox, геометрия выходит за viewBox, есть `<script>`/`on*`, растровый `<image>`, внешние ссылки.
- **Превью** 16, 24, 32, 48, 96, 256 px на фоне нужной темы; на 96 и 256 px — пунктир viewBox, красная рамка bbox и перекрестие центра.

Важно: bbox считается по геометрии без толщины обводки. У stroke-иконок видимый край шире на `stroke-width / 2`.

## Как оценивать

1. **Цифры**: `dx`/`dy` близки к 0 или смещение осознанное (оптическая компенсация). Поля симметричны или совпадают с соседями в группе.
2. **Мелкий размер**: на 16–24 px форма узнаётся, детали не слипаются, нет «грязи».
3. **Крупный размер**: нет зазоров, щелей, кривых стыков, лишних узлов.
4. **Оптика**: фигура выглядит по центру (не только математически), вес совпадает с соседями.
5. **Пара тем**: `-dark` и `-light` одинаковы по форме, обе читаются на своём фоне.
6. **Эталон**: если есть макет — наложение через `ref` совпадает по контуру и пропорциям.

## Проверка в реальном UI

После интеграции открой экран, где используется ассет, и проверь его в контексте: размер в кнопке, выравнивание с текстом, обе темы. Скриншот — в отчёт.

## Если браузера нет

Запасной вариант на macOS: `qlmanage -t -s 512 -o <папка> file.svg` даёт PNG-превью. Цифр центрирования он не даёт — это хуже стенда, отметь в отчёте.

## Отчёт

- Итоговые цифры стенда (смещение, поля).
- Скриншот превью и, если было, наложения на эталон.
- Что не проверено (реальное устройство, Electron, другие размеры).
