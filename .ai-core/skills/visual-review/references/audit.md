# Оценка B: технический аудит

Измеримое и проверяемое. Оценка каждого раздела 0–4 (0 — систематически сломано, 4 — отлично), итог из 24.

Правила проекта важнее общих web-советов. Например, safe area берётся из `--app-safe-area-*`, а не напрямую из `env()` — это правильно для Blind.

## 1. Доступность

- Контраст текста ≥ 4.5:1, крупного текста и ключевых элементов ≥ 3:1 — в обеих темах и во всех состояниях.
- Видимый фокус у всех интерактивных элементов; `outline: none` только с заменой через `:focus-visible`.
- Действия — `<button>`, навигация — ссылки/router; не `div`/`span` с `@click` (кроме осознанных случаев вроде клика по подложке модалки).
- Кнопки только с иконкой имеют доступное имя (`aria-label` через Locale; у `AppIcon` — `alt`).
- Декоративная графика скрыта (`aria-hidden`).
- Асинхронные сообщения (ошибки, тосты) объявляются (`aria-live`).
- Модалка: фокус внутри, Escape закрывает, фокус возвращается.
- Цвет не единственный сигнал.

## 2. Темы и tokens

- Цвета — через semantic tokens (`--app-color-*`), без сырых hex/rgb в компонентах. Исключение: технические маски (`mask-image` с `#000`) — это не цвет интерфейса.
- Компонент не собирает light/dark сам — только через tokens и `light-dark()`.
- Размеры, отступы, радиусы, типографика, z-index — из tokens; нет ручного домножения на `--app-scale`.
- Тема переключается на лету без «застрявших» значений.

## 3. Адаптивность и safe area

- Нет переполнения и горизонтального скролла на всех размерах из `capture.md`.
- Safe area — через `--app-safe-area-*`, не `env()` в компонентах.
- Visual breakpoints — CSS (`clamp`, `min`, `max`, media/container queries), не JS `window.innerWidth`.
- Touch-цели достаточного размера (ориентир — не меньше ~44×44 CSS px на телефоне; минимум WCAG — 24×24).
- Жесты работают под touch и имеют альтернативу (клик/клавиатура).
- Длинный текст: переносы, `min-width: 0` у flex-детей, обрезка где нужно.
- В модалках и шторках — `overscroll-behavior: contain`.

## 4. Локализация

- Нет hardcoded пользовательского текста в компонентах — всё через Locale.
- Ключ добавлен во все языки (`docs/interface/sections/localization.md`).
- Числа, даты — через `Intl.*`, plural — через `Intl.PluralRules`.
- Самый длинный перевод не ломает раскладку.
- Типографика текста: `…` вместо `...`, корректные кавычки для языка.

## 5. Motion

- `prefers-reduced-motion` учтён для неключевых анимаций — но обратная связь о смене состояния сохраняется.
- Анимируются `transform`/`opacity`, а не layout-свойства.
- Нет `transition: all` — свойства перечислены.
- Длительности и easing — из `tokens/motion.css` (технические значения конкретной анимации допустимы локально).
- Анимации прерываемы и не блокируют ввод.

## 6. Производительность и целостность

- Нет ошибок и предупреждений в консоли.
- Тяжёлые эффекты (`backdrop-filter`, большие blur и тени, SVG-фильтры) — осознанно и с учётом мобильного WebView.
- Нет чтения layout в цикле/на каждом кадре.
- Изображения с заданными размерами, без скачков layout.
- Используются существующие shared-компоненты, presets и contracts вместо дублей (`src/app/shared/components`, `src/app/shared/styles`).
- Код лежит в правильном слое (`docs/architecture/sections/app-flow.md`): view — точка сборки, не склад CSS.

## Быстрые поисковые проверки

Это подсказки, не вердикты. Каждую находку открой и проверь в контексте.

```bash
# сырые цвета в компонентах (маски с #000 — не находка)
grep -rnE "#[0-9a-fA-F]{3,8}\b|rgba?\(" src/app --include="*.vue"

# прямой env() вместо project safe-area tokens
grep -rn "env(safe-area" src/app --include="*.vue"

# transition: all
grep -rnE "transition:\s*all" src/app

# outline: none — проверить, есть ли замена через :focus-visible
grep -rnE "outline:\s*(none|0)" src/app

# клики на div/span — проверить, оправдано ли
grep -rnE "<(div|span)[^>]*@click" src/app

# визуальные breakpoints в JS (matchMedia для темы в useAppThemeMode — не находка)
grep -rnE "innerWidth|innerHeight|matchMedia" src/app

# пиксели в компонентах вместо rem/tokens
grep -rnE "[0-9]+px" src/app --include="*.vue"
```

Сузь путь до проверяемого экрана/компонента, чтобы не тонуть в шуме.
