# Съёмка: что и как фиксировать

## Запуск

- Web: конфигурация `web-dev` в `.claude/launch.json` или `npm run dev`. Порт может отличаться от 5173.
- Desktop (Electron): `npm run desktop:dev` — если проверка касается Electron-специфики (окно, ресайз, курсоры). Если запустить не удалось — честно отметь в отчёте.
- iOS/Android на реальном устройстве обычно недоступны — эмулируй мобильный viewport и отметь, что устройство не проверялось.

Проверяй тот же route, что видит игрок, и доводи до нужного состояния через реальный интерфейс (клики), а не подменой состояния в коде.

## Размеры (landscape)

| Размер | Что проверяет |
|---|---|
| `2560×1318` | design reference |
| `1920×1080` | обычный desktop |
| `1280×720` | маленькое окно |
| `2560×1080` | ultrawide 21:9 |
| `844×390` | телефон (с эмуляцией touch) |
| `1180×820` | планшет, близко к 4:3 |

Не обязательно снимать все размеры для каждой мелочи: для компонента — 2–3 показательных, для экрана — все.

## Варианты

- Светлая и тёмная тема.
- UI scale `small` / `default` / `large` (настройка в приложении).
- Самый длинный из поддерживаемых переводов — проверить переносы и переполнение.
- `prefers-reduced-motion: reduce`.

## Состояния

По ситуации: default, hover, focus, pressed, selected, disabled, loading, empty, error, success, открытая модалка поверх экрана, переход между экранами.

## Ввод

- **Клавиатура:** пройти Tab по экрану — фокус виден, порядок логичный, фокус не уходит из открытой модалки, Escape/«назад» закрывает верхний слой и возвращает фокус.
- **Touch:** на мобильном viewport — цели не мельче пальца, нет действий, доступных только по hover, жесты (удержание, перетаскивание) имеют альтернативу.
- **Мышь:** hover-состояния, курсоры на интерактивных элементах.

## Консоль

Сними ошибки и предупреждения консоли на проверяемом экране — они тоже находки.

## Сравнение «до/после»

При доводке снимай те же кадры (размер, тема, состояние) до и после — иначе улучшение не доказано.
