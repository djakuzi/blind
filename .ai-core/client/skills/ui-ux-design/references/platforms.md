# Платформы и адаптивность

Единый дизайн — это общая визуальная идентичность и смысл взаимодействий, а не пиксельная одинаковость. Различия в раскладке, плотности, размерах целей и поведении контролов допустимы, если они улучшают опыт и сохраняют узнаваемость.

## Модель размеров Blind

Подробно — `docs/client/interface/sections/ui-scale.md`. Кратко:

- Один общий масштаб UI через root font size (`min()` по ширине и высоте). Размеры — в `rem` и tokens.
- Layout при этом занимает реальный viewport.
- Не добавлять свои коэффициенты масштаба в компонентах и не дублировать `--app-scale`.
- Отдельные responsive-правила — только там, где реально ломается композиция. Через CSS (`clamp`, `min`, `max`, media/container queries), не через JS.
- Safe area — только через `--app-safe-area-*`, не через `env()` в компонентах.

## Desktop (Web, Electron)

- Мышь, hover, клавиатура, видимый focus.
- Компактные и широкие окна, полноэкранный режим, ultrawide (21:9, 32:9).
- Окно может менять размер на лету.
- Уместная информационная плотность — больше места не значит больше элементов.

## Mobile (iOS, Android через Capacitor)

- Touch: цели под палец, досягаемость большими пальцами в landscape.
- Safe areas, вырезы, home indicator, системные панели.
- Экранная клавиатура перекрывает часть экрана в полях ввода.
- Телефоны и планшеты, складные устройства, нестандартные пропорции (4:3, 5:4).
- Hover отсутствует.

## Размеры для проверки (landscape)

| Размер | Что проверяет |
|---|---|
| `2560×1318` | design reference |
| `1920×1080` | обычный desktop 16:9 |
| `1280×720` | маленькое окно |
| `2560×1080` | ultrawide 21:9 |
| `844×390` | телефон landscape |
| `1180×820` | планшет, близко к 4:3 |

Дополнительно: светлая и тёмная тема, длинный перевод, UI scale `small` и `large`.

## Платформенные отличия

- Не предполагай, что эффект (blur, backdrop-filter, тяжёлые тени, большие SVG-фильтры) одинаково быстро работает на всех платформах, особенно в мобильном WebView.
- Платформенная логика — через `core/platform`, не напрямую из компонентов (`docs/client/architecture/sections/core-flow.md`).
